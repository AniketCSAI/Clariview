# 🎙️ Clariview
## AI-Powered Interview Transcription & Highlight Generator

A web app that transcribes interview audio and generates smart highlights with timestamps.

## Features
- ✅ Hindi & English transcription
- ✅ Auto highlight generation
- ✅ Timestamp-based navigation
- ✅ Download transcript as JSON/TXT

## Tech Stack
- Backend: FastAPI + Faster-Whisper
- Frontend: HTML, CSS, JavaScript
